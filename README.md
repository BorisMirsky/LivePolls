# LivePolls

Система опросов и голосований в реальном времени.

Примерный аналог приложений `Slido` или `Mentimeter`. 




### Как пользоваться:

* git clone https://github.com/BorisMirsky/LivePolls.git

* Если зависимости не установились, то `dotnet restore`

* Запустить проект (f5)

* Тестирование только `backend` (страница `Swagger`): http://localhost:5063/swagger/index.html       

* Тестовая ui страница: http://localhost:5063/test-hub.html         




### Особенности реализации

- 'Авторизация' по имени. В имеющейся БД есть несколько юзеров.

- Один юзер в одном опросе голосует один раз.

- Возможно много подключений одновременно.

- Пользователи создают опросы и голосуют в реальном времени. Результаты обновляются на экране мгновенно.

- База данных на `SQLite` находится в `backend/LivePolls.DataAccess/Database/`

- Используется `Entity Framework`.

- Полноценного UI нет, тестовая страница реализована на чистом `js` внутри `html`, там же стили в блоке `<style>`. Находится в `LivePolls\backend\LivePollsSolution\LivePolls.Web\wwwroot\`

- Чтобы отображались старые опросы, их надо создать, а потом они должны устареть. В имеющейся БД уже есть один старый опрос.

- Нижний блок 'логи' может быть нужен только для условного админа.
